## 1. 读法说明

`onBindFields` 通过 `StoreObjectVisitor` 的三个虚函数把"成员偏移 → 键名 → 默认值"绑定起来，因此**注册顺序即结构体字段顺序**，对逆向 `SysSettingManage` 的内存布局很有用：

| 虚表偏移 | 类型 | 调用特征 |
|---|---|---|
| `+0x10` | `int` / `uint` | 默认值是整数（布尔型字段有时也用此接口） |
| `+0x30` | `bool` | 默认值是 `0` / `1` |
| `+0x38` | `std::string` | 默认值是全局字符串指针（显示为 `*(undefined8 *)puVar1`） |
| `+0x40` | `std::string`（本地常量） | `InsertLinkDefaultScheme` 的默认值来自栈上临时对象 `&local_48` |

`LanguageID` / `UseTopicContent` / `ComposeFont` / `NewMailSoundPath` / `CustomTrustedExt` / `AttachmentFileType` 的默认值是**全局变量指针**（`PTR_val_104aac930` 等），静态视图里读不到字面量——它们的真实默认值来自语言包或空字符串。

## 3. 值得单独说明的项

### 3.1 与 AI / 本地服务相关

| 键 | 默认 | 含义 |
|---|---|---|
| `EnableAIMCP` | **0** | 本地 HTTP 服务（SDK + MCP）总开关，出厂关闭 |
| `AIMCPPort` | **11328** | 本地 HTTP 服务端口（`skills/` 文档里的 11328 由此而来） |
| `ShowAIGlobalEntryFrame` | 0 | 是否显示 AI 全局入口浮层 |
| `HasAINotice` | 0 | 是否已展示过 AI 授权提示 |

### 3.2 与安全 / 合规相关

| 键 | 默认 | 含义 |
|---|---|---|
| `SupportSMimeSys` | **1** | 系统 S/MIME 默认开 |
| `SupportSMimeSM` | 0 | 国密 S/MIME 默认关（需服务端/证书支持） |
| `EnableAccountSafeLock` | 1 | 账号安全锁默认启用 |
| `DisableFullTextSearch` | 0 | 全文搜索默认开 |
| `HideMailImage` | 0 | **默认加载远程图片**（隐私/追踪像素面） |
| `SendReadOnlyMailNeedChange2TextMode` | 0 | 只读邮件发送时是否强制转纯文本 |
| `SupportFillAccountFromEnvKey` | 0 | 是否允许从环境变量填充账号（**自动化/CI 场景入口**） |
| `EnableCustomHttpsHandlerForCEF` | 0 | 是否为 CEF 注册自定义 HTTPS handler |

### 3.3 与远程管理 / 运维相关

| 键 | 默认 | 含义 |
|---|---|---|
| `EnableFolderSetting` | 7 | 文件夹设置能力位掩码（3 位全开） |
| `EnableImportMailsFuns` | 3 | 导入功能位掩码 |
| `EnableAccountSetting` / `EnableSystemSetting` | 1 / 1 | 账号/系统设置入口是否可见 |
| `SupportAdminHelpUnlock` | 0 | 是否允许管理员协助解锁 |
| `RecordUserOpbyWmsvr` | 0 | 是否把用户操作记录到 webmail 服务端 |
| `DisableChangeFetchmailpolicyType` | 0 | 是否禁止修改代收策略 |

> **注意**：这些 `Enable*Setting` 属于"**客户端本地的显示/能力开关**"，与 `conf/privatization-setting.js` 的租户级策略是两层——前者可被后者覆盖，后者可被服务端下发覆盖（见 `12` 第 1 节的四层模型，本表补充了"编译期默认"的确切值）。

### 3.4 与配置冲突的项

| 键 | C++ 默认 | `conf/syssetting.js` | 结论 |
|---|---|---|---|
| `UseRibbonBar` | **0** | `UseRibbonBar: true` | 发行配置覆盖了编译默认，实际界面用 Ribbon |
| `EnableUseRibbonBar` | **1** | — | 能力允许，但显示由 `UseRibbonBar` 决定 |

这印证了 `12` 的判断：**"出厂默认（C++）"与"发行配置（JS）"是两层**，读配置时必须先看 `conf/*.js` 再看代码默认值。
