# 官方客户端聊天附件预览分析

分析日期：2026-11-12。对象：仓库中的 `yx-packages/yuexiu_1786088172677.dmg`，官方 macOS 客户端 5.2.97。只读挂载后直接检查随包发布的明文 JavaScript；以下是静态代码证据，未登录生产账号验证接口响应。

## 官方调用链

证据文件：应用包内 `Contents/Resources/app/web/html/static/js/home.7717570b45127039f907.js`，SHA-256 为 `02375b706b0515d582366bea422d473da7c1a1e92f85ed84ec463d1c1cf26f34`。下列位置是解码后字符串的零起始字符偏移，可通过函数名重新定位。

1. `_msg.previewFile`（偏移 943008）处理普通文件消息 `msg_type=3`，读取 `content.download_url`、`file_name`、`extension`，交给 `previewStoreFile`。入口受 `useFilePreview`、快速下载和本地已有文件等配置影响。
2. `previewStoreFile`（偏移 546419）对图片走图片查看器，对 txt 下载到缓存后用系统打开，其余类型调用 `getPreviewFilePath`。
3. `getPreviewFilePath`（偏移 177122）请求 `GET {storeUri}/store/getPreviewUrl?fileId={download_url}`。注意配置中的 `storeUri` 已以 `/store` 结尾，完整路径可能是 `/store/store/getPreviewUrl`，不可擅自去重。
4. 响应 `s=1` 时，`r` 是预览页面 URL；失败时显示 `m`。HTTP 500 且没有错误说明时，官方提示不支持预览。
5. 官方取出页面 URL 内的 `furl`，解码并通过 `formatReqUrl` 应用 `imlayout.ReplaceRequestUri` 前缀映射，再写回 URL；最后调用 `openBrowserUrl` 打开独立 Electron 浏览器窗口。该调用未指定 `needTicket`，不能据此推断还需要 CAS 票据兑换。

因此，Word、Excel、PDF 的聊天预览依赖服务端生成的页面，未见该调用链在客户端使用 Word、Excel 或 PDF 解析器。具体转换引擎、生产服务可用性、转换耗时与文件限制不能由这段代码确认。

## 与云盘预览的区别

旧云盘分享走 `openapi/stream/preview`，WOPI 分支读取 `preview-url` 响应头；新团队文档走 `/v1/files/{fileId}/preview`。这两者与聊天存储文件的 ID、接口和响应格式不同，不能拿团队文档接口直接预览聊天附件。

## 当前移植

- `YX/src/services/im/media.ts` 新增聊天预览请求：使用 Tauri HTTP 和已有 token 刷新逻辑，按存储接口的 `s/r/m` 判断结果，只接受 HTTP(S) 页面地址。
- `YX/src/components/MessageContent.vue` 对 doc、docx、xls、xlsx、ppt、pptx、pdf 增加预览按钮；点击文件卡片也预览，下载按钮独立保留。重复点击会被拦截，失败显示可读提示并隐藏错误中的请求地址。
- 历史消息与合并转发复用同一组件，因此一并获得入口。完整外部下载 URL 缺少明确的存储文件 ID，仍只提供下载。
- 当前用系统默认浏览器展示服务端页面，与官方的独立 Electron 窗口存在表现差异；没有新增第三方文档转换服务，也不把文档全文读入 WebView。
- 已补齐官方 `ReplaceRequestUri` 映射来源：登录 bundle 的 `getEnterpriseInfo` 调用 `GET {uamApiUri}/v1/enterprises/info?eCode=...`，读取 `data.details.indiviConfig`；主界面将其作为 `UIConfig` 解析为 `imlayout`。复刻版在需要映射 `furl` 的附件预览中按账号与企业查询、缓存配置，使用 JSON5 安全解析后仅替换第一个匹配前缀；只接受无 userinfo 的 HTTP(S) 地址。查询失败或超过 4 秒继续打开原预览地址，不缓存失败，也不凭空追加 token。
